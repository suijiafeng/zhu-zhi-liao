# 竹知了

竹知了(竹蝉)是庙会里几毛钱一个的老玩具:一只竹哨系在线上,抡圈甩起来靠摩擦和气流发出"哇哇"的连绵叫声。这个项目把它做成了一个浏览器小游戏——画圈甩动、控制转速落在节奏区里得分,蝉鸣声是用 Web Audio 现场合成的,不是录音。

在线地址: https://suijiafeng.github.io/zhu-zhi-liao/

## 玩法

按住画面绕中心画圈甩动,指针落在绿区能连击加分,红区会把线绷断。空格或按钮可以掐线消音。节奏区会缓慢漂移;野蝉对唱、阵风、松香、野猫、金蝉等事件会随机出现,攒满欢呼可进狂欢。连击够高会获得护盾。绿区蓄满飞天值后可放飞(按钮 / F 键 / 手机摇一摇)。

每局会随机抽一种彩头场景(夜场灯会、毒日头、中秋月圆、十二生肖等),节奏区宽窄、漂移速度、得分倍率与画面氛围都不一样。玩得多了会解锁印章成就,场景与印章都存在浏览器本地。

两种模式:

- **经典**:六十秒庙会演奏会,时间到结算得分与称号
- **无尽**:难度随时间抬升,断线或观众散场即结束,比谁甩得更久

## 声音是怎么做的

真实的竹知了靠线在松香上"黏—滑"交替摩擦,经过竹筒开口的薄膜共鸣放大。代码里用一个低频锯齿波过失真,叠加一个 LFO 调幅模拟这个黏滑脉冲,再过几层带通滤波模拟腔体共振,转速慢时听着像蛙鸣,甩快了才变成"嘎哇"的知了声。具体实现在 [cicadaVoice.js](src/audio/cicadaVoice.js) 里的 `createCicadaVoice`。

## 跑起来

```bash
npm install
npm run dev
```

```bash
npm run build   # 构建
npm run preview # 本地预览构建产物
```

## 部署

推到 `main` 分支会触发 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),自动构建并发到 GitHub Pages。仓库 Settings → Pages 里 Source 要选成 GitHub Actions,只需要设一次。
